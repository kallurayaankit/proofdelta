A packaging proof says 160 g. The approved file says 180 g. Would you catch it?

I’m building ProofDelta to help reviewers compare the selectable text in an approved packaging PDF and a printer’s proof, then work through the differences with page context.

The prototype includes a layered review workbench, keyboard navigation, follow-up flags and a downloadable HTML report. PDFs are processed locally in the browser.

The short illustrated walkthrough uses fictional sample files with three deliberate changes: a weight change, an ingredient substitution and an added printer reference.

Built with React, with a Rust service tested locally. Checkout is currently a simulation. This is a text-review aid, not print sign-off or artwork validation.
